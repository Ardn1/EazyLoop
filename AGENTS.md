# EazyLoop

Основное рабочее дерево находится в `G:/EazyLoop`. Старый путь `G:/LoopDeck` может встречаться в контексте чатов.

Исходники приложения лежат в `src/` и сгруппированы по разделам из README. Добавляйте C# и XAML в соответствующий раздел, а файл окна и его code-behind держите рядом.

## Общий выпуск для параллельных чатов

- Разрабатывайте и проверяйте отдельные изменения через `dotnet build EazyLoop.csproj` с .NET 10 SDK. На этой машине SDK также доступен в `%LOCALAPPDATA%/LoopDeckBuild/dotnet/dotnet.exe`. Если нужен отдельный worktree, перенесите проверенные изменения в основное рабочее дерево перед выпуском.
- Перед выпуском проверьте, какие чаты сейчас работают над EazyLoop. Согласуйте состав сборки и назначьте один чат для выпуска. Готовые изменения можно объединить в один выпуск. Из остальных чатов передавайте статус готовности тому, кто выпускает сборку.
- Для пользовательской сборки из основного рабочего дерева запускайте `.\scripts\Publish-Local.ps1 -UpdateDesktopShortcut`. Скрипт берёт общую блокировку и выдаёт следующий свободный номер. Если выпуск уже идёт, дождитесь результата и используйте его, если ваши изменения вошли в сборку.
- Храните одну папку `dist/<версия>` на выпуск. Оставляйте имя папки числовым, а состав выпуска перечисляйте в сообщении пользователю. Версию в заголовке и бейдже приложение читает из сборки. Номер в `EazyLoop.csproj` обновляет скрипт.
